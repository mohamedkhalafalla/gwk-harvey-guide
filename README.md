# Harvey مع Claude Code: الشرح

ده شرح من **Grow With Khalaf** لتسطيب [Harvey](https://github.com/ethanplusai/harvey)، أداة open source بتحوّل Claude Code لـ SDR: بتدوّر على الشركات، وتعرف مين مستعد يشتري دلوقتي من الـ signals، وتكتب cold email وتتابع. ومفيش إيميل بيطلع غير بموافقتك.

**الدليل الكامل خطوة بخطوة: [mohamedkhalafalla.github.io/gwk-harvey-guide](https://mohamedkhalafalla.github.io/gwk-harvey-guide/)**

## باختصار

</div>

```bash
git clone https://github.com/ethanplusai/harvey.git
cd harvey
claude   # then: "set up Harvey for me"
```

<div dir="rtl">

بعدها: `harvey train <موقعك>`، و`harvey signals --confirm free`، و`harvey discover`، و`harvey dashboard`، و`harvey run`.

Harvey من تطوير [ethanplusai](https://github.com/ethanplusai/harvey) برخصة MIT. إحنا مش تابعين لمطوّره ولا لـ Anthropic.
